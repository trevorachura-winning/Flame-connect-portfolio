# Restaurant Ordering & Booking Concept

**Category:** Hospitality software / web application  
**Status:** Demo MVP; not a live restaurant service  
**Type:** Software concept / portfolio implementation

## Overview
A mobile-friendly restaurant ordering concept using Ugandan menu examples and UGX sample prices to demonstrate browsing, ordering, and booking request flows.

## Selected capabilities
- Searchable menu with category filters.
- Shopping cart, quantities, and pickup or delivery checkout forms.
- Table reservation requests.
- Server-side pricing validation and an optional Supabase-backed request store.

## Technology
Next.js, React, TypeScript, and optional Supabase integration.

## Access
The codebase is privately maintained. The concept must not be represented as a live ordering or reservation service: demo submissions are not real bookings or orders.

> Representative menu items, prices, and business details are samples.
